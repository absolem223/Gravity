## 📁 Estructura Principal del Repositorio

- `game/`: Código del juego Godot 4.x (Desacoplado del Workspace).
- `sandbox/`: Experimentos, benchmarks y prototipos aislados.
- `docs/`: Fuente Única de Verdad (SSOT).
  - `agents/`: Roles, manuales y límites para Agentes de IA.
  - `specs/`: Especificaciones técnicas funcionales (SPECs).
  - `rfcs/`: Solicitudes de comentarios y cambios estructurales.
  - `adrs/`: Architecture Decision Records.
  - `conventions/`: Estándares de código, Git y colaboración.
- `memory/`: Memoria institucional acumulada del estudio.
- `assets/`: Assets fuente y procesados (Git LFS).
- `tests/`: Suites de pruebas unitarias, integración y red.
- `tools/`: Utilidades CLI, linters y scripts auxiliares.
