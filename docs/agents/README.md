# docs/agents/ — DIRECTIVAS PARA AGENTES IA ESPECIALIZADOS

Este directorio contiene los manuales operativos obligatorios para cada rol de Inteligencia Artificial que participe en el desarrollo de **PROJECT GRAVITY**.

## 🛡️ Directiva General

Cada agente de IA debe actuar dentro de los límites estrictos fijados en su manual de rol. Todo agente **debe leer compulsivamente** la documentación obligatoria de su rol antes de modificar cualquier línea de código.
