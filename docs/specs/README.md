# docs/specs/ — FUNCTIONAL SPECIFICATIONS (SPECs)

Las **Specifications (SPECs)** son los documentos funcionales y técnicos de cada sistema del juego.

## 📌 Propósito

Las SPECs son la fuente principal de verdad utilizada por los agentes de IA y desarrolladores para implementar funcionalidades en `game/modules/`. Ningún sistema de gameplay existe sin una SPEC previa.

## 📋 Lista de SPECs Planeadas para Fases Futuras:

- `movement.md`: Especificación de mecánicas de movimiento autoritativo y predicción.
- `camera.md`: Comportamiento de cámara, jerarquía y oclusión.
- `vision.md`: Sistema de línea de visión, fog of war y visibilidad de red.
- `weapon.md`: Contratos de componentes de armas, balística y dispersión.
- `drone.md`: Entidades autónomas de asistencia, control y sincronización.
- `hack.md`: Mecánicas de hackeo e interacción lógica.
- `ui.md`: Arquitectura de interfaz, vistas y reactividad de estado.
- `network.md`: Especificación de empaquetado, canales y serialización.
