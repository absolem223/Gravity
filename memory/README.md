# memory/ — MEMORIA INSTITUCIONAL DEL PROYECTO

Este directorio contiene el conocimiento acumulado a lo largo del desarrollo de **PROJECT GRAVITY**.

## 🧠 Propósito

A diferencia de las SPECs (que describen *cómo debe ser*) y los ADRs (que describen *qué decidimos*), la **Memoria Institucional** almacena el *aprendizaje empírico*, errores superados, descubrimientos del motor y guías operativas.

## 📄 Archivos de Memoria

- `lessons_learned.md`: Errores cometidos y lecciones extraídas.
- `known_issues.md`: Bugs conocidos, limitaciones técnicas o deuda temporal tracking.
- `performance_notes.md`: Benchmarks empíricos y notas de optimización en Godot 4.
- `godot_notes.md`: Quirks, peculiaridades y comportamientos indocumentados de Godot 4.x.
- `pixel_art_guidelines.md`: Estándares de resolución, paletas, importación y filtrado de assets 2D/Pixel Art.
